An **AI-powered trip planning platform** that creates **personalized itineraries** based on your preferences.  
With **AI recommendations, interactive maps, and smart scheduling**, this project transforms the way you plan your travel.

🔗 **Live Demo:** [WayQuest AI](https://wayquestai.vercel.app)  
📦 **Repository:** [AI Trip Planner](https://github.com/MKG0007/Ai-Trip-Planner)

---

## ✨ Features
- 🤖 **AI-Powered Itineraries** – Personalized travel plans with Gemini API.  
- 🗺️ **Interactive Map Support** – Real-time route visualization using Mapbox.  
- 📊 **Smart Recommendations** – Optimized destinations, activities, and schedules.  
- 🔐 **Secure Authentication** – User login/signup with Clerk.  
- ⚡ **Scalable Data Handling** – Convex backend for reliable data management.  
- 🎨 **Modern UI/UX** – Clean, responsive design powered by Tailwind CSS.  
- 🚀 **Fast Deployment** – Hosted seamlessly on Vercel.

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/MKG0007/Ai-Trip-Planner.git

# Navigate into the project folder
cd Ai-Trip-Planner

# Install dependencies
npm install

# Add environment variables in `.env.local`
NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key
NEXT_PUBLIC_MAPBOX_TOKEN=your_mapbox_token
CONVEX_DEPLOYMENT=your_convex_url
CLERK_API_KEY=your_clerk_key

# Start the development server
npm run dev
